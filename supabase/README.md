# Integración prevista

Supabase/Postgres/PostGIS se incorporará cuando se autorice el catálogo real.
No hay proyecto remoto, credenciales, migraciones ni tablas expuestas en esta
maqueta. Toda futura tabla o almacenamiento debe tener RLS y pruebas de
acceso anónimo, propietario, tercero y moderador antes de publicarse.

# Pantallas funcionales de la candidata 0.2

Capturas de la exportación web compartida con la app, en Chromium móvil y tema
oscuro del sistema. No son una APK instalada ni pruebas de GPS: La Ligua se eligió
manualmente. Las ilustraciones están rotuladas y los lugares esperan verificación.

- [Inicio: Valparaíso → Petorca → La Ligua](pantalla-inicio.png).
- [Explorar: filtros por comuna y mapa interactivo](pantalla-explorar.png).
- [Ficha de Matichoc con foto propia del catálogo](pantalla-ficha.png).

El fondo OSM no cargó por la restricción de red del entorno; se conservan límites
y puntos con su aviso. No se ha sustituido el mapa con una imagen ficticia.
Las capturas se regeneran en CI y acompañan cada candidato antes de instalar.

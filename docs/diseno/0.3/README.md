# Vistas funcionales 0.3

Capturas de la exportación web en Chromium móvil. La Ligua se elige manualmente;
no son pruebas de GPS ni de instalación Android. Oscuro y claro usan el mismo
selector y recorrido. Los paisajes son ilustraciones de referencia.

- [Inicio con indicación del gesto acordado](pantalla-inicio.png).
- [Selector: dieciséis regiones y líneas](pantalla-selector.png).
- [Recorrido por el país, capturado durante la animación](pantalla-recorrido.png).

La prueba del selector comprueba que todos sus enlaces estén en pantalla a
360 × 640, sin desplazar la página y con blancos de toque de 44 puntos. El recorrido
muestra un indicador que se mueve: una captura solo representa un instante.
Las capturas de CI acompañan cada APK; la revisión se hace antes de fusionar.

[Video funcional del recorrido por Chile](recorrido.webm), grabado en Chromium
móvil con el mismo código de interfaz; no sustituye la prueba de la APK nativa.
Datos de referencias © Colaboradores de OpenStreetMap, ODbL 1.0; geometrías de
Natural Earth en dominio público. Las ilustraciones no son fotos de esos lugares.

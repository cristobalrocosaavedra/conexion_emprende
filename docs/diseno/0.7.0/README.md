# Vistas de la candidata 0.7.0

Capturas funcionales de la exportación web móvil, tomadas con Playwright el 26-10-2026. No son imágenes generadas de una interfaz imaginaria: la app carga las ilustraciones de la [colección territorial](../coleccion-0.7/README.md).

- [Inicio en La Ligua](pantalla-inicio.png): interior de Petorca y prioridad local; selección manual, sin GPS físico.
- [Inicio en Rapa Nui](pantalla-rapa-nui.png): paisaje propio, referencias insulares separadas.
- [Inicio en Magallanes](pantalla-magallanes.png): portada regional austral.
- [Mi viaje](pantalla-ruta.png) y [mapa de viaje](pantalla-mapa.png): controles y trazado conservados. Transporte y GPS simulados con fixtures públicos rotulados; no son una prueba física de conducción. Teselas externas bloqueadas en esta prueba para comprobar funcionamiento sin ellas.

Las ilustraciones se identifican como tales. No se añaden registros ni se promueven fichas a verificado. Matichoc conserva su logo completo. Estas vistas se muestran antes de ofrecer una descarga nueva; la APK nativa se compila y verifica separadamente en GitHub Actions.

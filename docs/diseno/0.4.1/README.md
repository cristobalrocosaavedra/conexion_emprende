# Revisión visual 0.4.1 — rutas de prueba sin VPS

Capturas funcionales de Chromium móvil, previas a la APK. No son pruebas físicas de GPS Android/iOS.

- [Inicio en La Ligua elegida manualmente](pantalla-inicio.png).
- [Mi viaje sin formulario de servidor](pantalla-ruta.png).
- [Mapa con trazado dentro de la app](pantalla-mapa.png).

El recorrido mostrado entre dos referencias públicas de Arica proviene de una respuesta real del motor local, suministrada al cliente mediante transporte simulado. La verificación del proveedor público real es una prueba de integración diferente en Actions (La Ligua–Papudo y Santiago–La Serena); su resultado debe comprobarse antes de ofrecer la APK. Las fichas siguen pendientes de verificación y los paisajes son ilustraciones.

La pantalla muestra el servicio temporal FOSSGIS/OSRM y avisa de registros del proveedor. Hay botones de cálculo/inicio sin configurar VPS. El paquete de instalación contiene una sola APK, sin estas imágenes. La Ligua elegida manualmente no se presenta como un GPS obtenido.

Datos © Colaboradores de OpenStreetMap, ODbL 1.0; límites Natural Earth; Leaflet BSD. Atribución del motor/proveedor en el mapa y enlaces de condiciones/corrección de OSM. Si el fondo no carga, se conserva el aviso de falta de teselas, puntos y ruta.

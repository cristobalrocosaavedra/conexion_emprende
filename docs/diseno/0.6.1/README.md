# Capturas funcionales 0.6.1

26-10-2026. Capturadas con Playwright sobre la exportación web de Expo, no
con un Android físico. Se conservan los temas claro y oscuro.

- Inicio: Valparaíso muestra 90 referencias regionales y 11 en La Ligua elegida
  manualmente, con acceso a toda la región y Rapa Nui.
- Rapa Nui: catálogo insular con cuatro referencias OSM pendientes y aviso de
  llegada en avión. La publicación SERNATUR enlazada se identifica como de 2022.
- Viajes separados: tres lugares guardados, un recorrido continental y otro en
  Rapa Nui; no se dibuja una conexión por océano.
- Aviso de traslado: intento de iniciar hacia Rapa Nui desde coordenadas sintéticas
  continentales; la consulta vial se bloquea localmente, sin enviar esa posición.
- Ruta/mapa: prueba visual anterior de Arica, con transporte simulado y GPS
  sintético rotulado; no representan una navegación del titular.

Los mapas de estas pruebas tienen teselas externas bloqueadas deliberadamente.
Las ilustraciones son referencias genéricas. Las vistas principales se muestran
antes de ofrecer la APK; firma y compatibilidad nativas se comprueban en Actions.
Estas imágenes no se incluyen en el artefacto de instalación.

# Datos abiertos de la candidata 0.6.1

Datos © Colaboradores de OpenStreetMap · ODbL 1.0. Este directorio conserva
el extracto exacto de 31 referencias de esta versión, incluidas cuatro de Rapa
Nui. No incluye datos personales de colaboradores ni ubicación de viajeros.

- [Descargar/consultar el extracto completo](osm-chile.json).
- [Licencia íntegra ODbL 1.0](../ODbL-1.0.txt).
- [Procedencia de la ampliación Rapa Nui](../rapa-nui/procedencia.json).
- [Geometría original seleccionada](../rapa-nui/extracto.osm).

Referencias comunitarias pendientes: los centros cartográficos no certifican
entradas, horarios, apertura ni tarifas. El resto del catálogo editorial
conserva sus propias fuentes; no se relicencia como OSM.

La oferta de datos está separada del instalador: el artefacto de Android
contiene solo la APK. Este snapshot permanece sin modificar en versiones
posteriores; el enlace de la app usa un commit inmutable para seguir disponible
aunque se cierre o elimine la rama de trabajo.
